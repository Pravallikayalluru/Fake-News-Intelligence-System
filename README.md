# CredibilityLens — Explainable News Credibility Analysis

CredibilityLens is a Streamlit application that analyses news text using a hybrid machine-learning pipeline.

## Key components
- TF-IDF text features and ten linguistic / writing-style features.
- Class-balanced Logistic Regression.
- Artifact masking to investigate source and formatting shortcut learning.
- Five experiments: style-only, text-only (raw), hybrid (raw), text-only (masked), and hybrid (masked).
- Word-level prediction cues, writing red flags, and comparison with typical real-news writing patterns.

> **Important:** The credibility score reflects patterns learned from labelled training data. It is not a fact-check and does not establish whether a claim is true.

## Repository files

| File | Purpose |
|---|---|
| \`app.py\` | Streamlit user interface |
| \`core.py\` | Text cleaning, artifact masking, style features, red-flag logic |
| \`train.py\` | Dataset loading, five experiments, evaluation, and model generation |
| \`requirements.txt\` | Python dependencies |
| \`bundle.joblib\` | Trained model bundle generated by training |
| \`results.json\` | Measured experiment results |
| \`ablation.png\` | Five-experiment accuracy chart |

## Run locally

Use Python 3.10 or 3.11.

\`\`\`bash
python -m venv .venv
\`\`\`

Windows PowerShell:

\`\`\`powershell
.\\.venv\\Scripts\\Activate.ps1
\`\`\`

Install and train:

\`\`\`bash
python -m pip install --upgrade pip
pip install -r requirements.txt
python train.py
\`\`\`

By default, the training script downloads the configured public dataset through KaggleHub. To use your own CSV:

\`\`\`bash
python train.py --csv path/to/news.csv
\`\`\`

The CSV must contain \`text\` and \`label\` columns. An optional \`title\` column is joined with the article text. Labels should be \`FAKE\` and \`REAL\`.

Training generates \`bundle.joblib\`, \`results.json\`, and \`ablation.png\`.

Start the application:

\`\`\`bash
streamlit run app.py
\`\`\`

If \`bundle.joblib\` is not present, the app attempts first-run training automatically using the configured KaggleHub dataset. For predictable deployment, it is recommended to train locally first and include the generated model bundle and results files in the repository when they fit GitHub's file-size limits.

## Deploy on Streamlit Community Cloud

1. Push this repository to GitHub.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Select **Create app**.
4. Choose this repository, branch \`main\`, and main file path \`app.py\`.
5. Deploy. Streamlit Community Cloud installs packages from \`requirements.txt\`.

If the model bundle is not committed, the app's first startup attempts to download the dataset and train the model. This can take several minutes. If that environment cannot access the dataset, train locally and add \`bundle.joblib\`, \`results.json\`, and \`ablation.png\` to the repository.

If \`bundle.joblib\` is larger than GitHub's normal file limit, use Git LFS or external model storage rather than committing it as a regular Git blob.

## Evaluation and responsible use

The Research Results tab reports measured metrics generated by \`train.py\`. Do not interpret a sample credibility score (for example, 100/100) as model accuracy. Short text can be less reliable. Always verify important claims with original reporting and trusted fact-checking sources.
