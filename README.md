\# 📰 AI Fake News Intelligence System





\## Project Overview



An AI-powered fake news detection system using Natural Language Processing and Machine Learning.



The system predicts whether a news article is REAL or FAKE and provides additional credibility analysis.





\## Features



\- Fake / Real News Classification

\- TF-IDF Text Representation

\- Ensemble Machine Learning Model

\- Sentiment Analysis

\- Clickbait Detection

\- Risk Level Prediction

\- Streamlit Web Interface





\## Technologies Used



\- Python

\- Scikit-learn

\- NLP

\- Streamlit

\- Machine Learning
